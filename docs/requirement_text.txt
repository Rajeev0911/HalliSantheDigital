1. Software Requirements
1.1 Development Tools
•	Android Studio (Latest Stable Version — Hedgehog or above)
•	Java Development Kit (JDK 17 or above)
•	Git — for version control
•	GitHub — remote repository hosting
1.2 Programming Language
•	Primary Language: Java (or Kotlin — either is acceptable)
•	XML — for Android layout files
1.3 Backend & Database
•	Firebase Firestore — cloud database for product listings
•	Firebase Authentication — for user login (Phone/OTP)
•	Firebase Storage — for storing product images
•	Room Database (optional) — for offline caching
1.4 Android Libraries & Dependencies
•	RecyclerView + GridLayoutManager — for product grid display
•	Glide or Picasso — for image loading and caching
•	Compressor library — for image compression before upload
•	Material Design Components — for UI elements
•	Firebase SDK — for all Firebase services

6. Success Criteria Checklist
The following criteria MUST all be met before final submission:

□	Clicking a product opens a detailed view with a clear 'Call to Action' button.
□	Search functionality works correctly for product names (real-time filter).
□	Empty State is handled gracefully — shows friendly UI when no products exist.
□	UI is colorful and vibrant, reflecting a traditional Indian market aesthetic.
□	Artisan can upload a product with Name, Price, Category, and 1 Photo.
□	Image compression is implemented before uploading to Firebase Storage.
□	App works on Android 8.0+ without crashes.
□	All Firebase read/write operations complete without errors.
